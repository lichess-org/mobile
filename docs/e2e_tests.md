# End-to-end tests (Patrol)

End-to-end tests drive the real app on an Android emulator or device. They live in
`patrol_test/` and use [Patrol](https://patrol.leancode.co). They are not run by `flutter test`
and are not part of CI.

## Requirements

- An Android emulator or device, fully booted.
- The Patrol CLI: `dart pub global activate patrol_cli`. The CLI version must match the `patrol`
  package version in `pubspec.yaml`, see the
  [compatibility table](https://patrol.leancode.co/documentation/compatibility-table).
- The usual project setup: `flutter pub get` and `dart run build_runner build`.

## Running

```sh
patrol doctor
patrol test
```

To run a single file: `patrol test --target patrol_test/puzzles_tab_test.dart`.

While writing a test, `patrol develop --target patrol_test/puzzles_tab_test.dart` builds the app
once and hot restarts the test when you press `r`.

Tests target the same server as `flutter run` (lichess.dev by default) and accept the same
`--dart-define` flags.

## Notes

- The test setup mirrors `main()` in `lib/main.dart`. When `main()` changes, update the setup in
  `patrol_test/` accordingly.
- `patrol` is a dev dependency and is not part of release builds.
- `patrol_test/test_bundle.dart` is generated by the CLI and ignored by git.
- Android only for now.
